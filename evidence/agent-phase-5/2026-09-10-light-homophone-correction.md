# 2026-09-10 射灯／筒灯语义谐音修正

用户已确认当前 26 个照明控制实体的中文名对应关系无误，并要求处理“射灯”“筒灯”的同音转写。
近期审计中实际出现“打开客厅设登”“把客厅的设灯打开”；此前只处理窄格式的“打开客厅设灯”，
不足以覆盖这两句。这里确认的是文本转写结果，不是基于保留的原始录音进行听辨。

## 实现

- 在设备语义层增加限定词形校正：`[射设社涉摄舍][灯登]` 对应射灯，
  `[筒桶统同铜通][灯登]` 对应筒灯；保留此前“顶灯”对应吸顶灯的简称支持。
  除已观察到的“设灯／设登”外，其余是测试候选，不能声称均在现场出现过。
- 支持直接开／关、“把……打开／关掉”、礼貌前缀、“的”“一下”，以及状态查询。
  修正限定在单设备请求的灯具名称，结合固定房间词表和当前允许的能力匹配；不做任意中文
  拼音模糊匹配，不改动房间、动作、否定词或多句命令。
- Router 仅增加同音词的语义提示，仍按原始文本切分。Robot 获取原名、规范名、唯一 alias
  与动作提示，在执行前再次核对选择。原始 user message、STT 审计文本与 source span 均保留。
- 已知灯型但对应房间未接入、同名多目标、模型选择的目标／开关方向不一致时不执行。
  通用“客厅灯”等表达保留既有路由与澄清逻辑，不误归为缺失的具体灯型。
- 重放发现“他说把客厅的设灯打开”会被模型归为 Robot，因此增加有限的第三人称转述拦截；
  Router 和 Robot 分别校验，避免绕过路由直接执行。该规则不代表能识别所有转述句。
- 保留 35B、原 STT 模型、已确认的 26 个照明实体和当前三角色配置；仅部署 Agent 改动。
