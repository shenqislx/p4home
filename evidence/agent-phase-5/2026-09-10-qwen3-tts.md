# Qwen3 中文 TTS 接入与验收（2026-09-10）

## 结论

用户拒绝之前的 Kokoro 与 macOS Tingting 试听，要求更换中文模型。本机常驻服务已切换到 `mlx-community/Qwen3-TTS-12Hz-1.7B-CustomVoice-6bit`，Human 使用 Serena，Robot 使用 Vivian。用户随后明确确认：**“Serena 的音色通过验收”**。Human 默认保留该音色。

此结论仅覆盖 Serena 音色听感，不扩大为所有中英混读、Robot 的 Vivian、真人唤醒率或设备控制全部通过。35B 对话模型 `qwen3.6:35b-mlx`、Human/Robot/Cat 能力与既有局域网 HTTP 连接保持不变。

后续收尾发现播放协调器仍使用旧模型音色表，已修复，并完成 Robot 只读查询、Human 聊天、Avatar 移动三条语音交付复验。详见 [产品收尾记录](2026-09-10-product-closeout.md)。下文保留本次接入时的原始失败，不用后续成功覆盖。
